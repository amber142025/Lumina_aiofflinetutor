LUMINA — COMPLETE OFFLINE-FIRST AI LEARNING TUTOR
=================================================

This is a new implementation created from the requested product requirements.

STACK
-----
Mobile: Flutter / Dart
Backend: FastAPI / Python
Cloud database: PostgreSQL
Offline database: SQLite
Auth: JWT access + rotating refresh tokens
Authorization: RBAC + permission checks
Media: URL metadata + optional device downloads
AI: local deterministic tutor engine + cloud AI integration endpoint

PROJECT
-------
Mobile/    Flutter application
Backend/   FastAPI application
Database/  PostgreSQL schema/seed SQL
Docs/      architecture and feature notes

QUICK START
-----------
1. Backend
   cd Backend
   python -m venv .venv
   Windows: .venv\Scripts\activate
   macOS/Linux: source .venv/bin/activate
   pip install -r requirements.txt
   copy .env.example .env   (Windows)
   # or cp .env.example .env
   python seed.py
   uvicorn app.main:app --reload --host 0.0.0.0 --port 8000

2. Mobile
   cd Mobile
   flutter pub get
   flutter run

3. API URL
   Android emulator: http://10.0.2.2:8000
   Physical phone: replace API base URL in lib/config/app_config.dart with
   your computer's LAN IP, e.g. http://192.168.1.10:8000
